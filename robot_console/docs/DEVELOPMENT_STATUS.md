## 接下来需要打通

1. **真实到点导航**：rqt 目标桥接 `/goal_pose`、`/set_motion_enabled`、`/clear_goal`，明确接受、执行、到达、取消和失败反馈。当前真实目标仍在 RViz 设置。
2. **导航异常停车**：检查定位/扫描新鲜度、无路径行为和控制源独占，再做低速到点与动态障碍验收。当前 `custom_nav_node.cpp` 在无 A* 结果时存在直线回退，不能仅凭显示路线判断避障有效。
3. **相机**：把 RTSP/图像显示嵌入 rqt，处理掉线和资源释放；现用原 `scripts/cam_view.py` 独立窗口。
4. **变化环境下恢复定位**：记录新增桌子后的扫描与位姿，在未变化的墙面区域优先评估匹配；研究距离场、离群点抑制与多候选歧义检测后再决定实现。当前未实现新的恢复算法；部署的 NX 不订阅 `/initialpose`，界面发布初始位姿本身不能恢复定位。
5. **真实键盘接管**：部署速度仲裁、失焦/通信中断停车和设备侧超时保护；当前真实速度发布保持禁用。
6. **重启恢复**：完成授时持久化、感知恢复和重启回归；草稿在 `../drafts/reboot_setup/`，未安装。

## 仓库整理约定

- `robot_console/` 是 rqt 后续维护位置，源码、工具、历史地图、截图、验证记录及本接口文档集中在这里。
- `docs/WEBSOCKET_API.md` 是用户提供的接口参考原文，用于核对协议；固件实际响应仍以实测为准。
- 原导航启动脚本保持原样；rqt 自带 `COLCON_IGNORE`，不加入导航工作区的默认 colcon 构建，单独执行 `./build.sh`。
- `build/`、`install/`、`log/`、`runtime/`、Python 缓存和本机 `.desktop` 快捷方式不提交。已有 `validation/` 日志是历史验收材料，保留版本管理。
- 旧截图/日志可能记录迁移前的绝对路径，作为历史证据保留；运行入口和源码不依赖旧 Codex 工作目录。
